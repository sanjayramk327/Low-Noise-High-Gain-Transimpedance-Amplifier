# Low-Noise-High-Gain-Transimpedance-Amplifier
Designed a CMOS transimpedance amplifier in 0.13 µm CMOS technology for low-noise sensor interfaces, targeting high transimpedance gain, wide dynamic range, and improved bandwidth. Performed transistor-level design, simulations, and full-custom layout with DRC/LVS verification and post-layout PEX analysis.
